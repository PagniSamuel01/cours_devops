# ContactsManager

## Description
Application Java qui permet de gérer une liste de contacts.
L'utilisateur peut ajouter, afficher et rechercher des contacts.

## Classes
- **Contact** : représente un contact avec un nom et un numéro de téléphone
- **ContactsManager** : gère la liste des contacts

## Fonctionnalités
- Ajouter un ou plusieurs contacts
- Afficher tous les contacts
- Rechercher un contact par son nom
- Validation du numéro de téléphone (chiffres uniquement)
